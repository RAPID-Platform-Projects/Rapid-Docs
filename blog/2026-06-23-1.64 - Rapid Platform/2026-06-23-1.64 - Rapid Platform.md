# v1.64 — Rapid Platform

We're excited to announce new features live on Rapid Platform **Tuesday, June 23rd**

## Features

### Experiences are now Workspaces

Experiences have been renamed to Workspaces throughout the platform, including labels, routes and search. You can now link a menu item to a Workspace, which displays that Workspace's full menu as nested children. Any changes made to the linked Workspace's menu are reflected automatically, without needing to re-save the menu that links to it.

### Tab permissions

You can now limit which tabs in a Tab Strip are visible to specific users or groups. Tabs a user doesn't have access to are hidden when they view the page, while all tabs remain visible when editing the Tab Strip in Designer.

### Wait for all Inclusive Gateway paths

Inclusive Gateways in Workflow can now wait for the outcomes of all active paths before the process continues. This is useful for scenarios such as onboarding, where a user may be provisioned to several systems and the process can't proceed until every system has been provisioned.

### Application principals

We've added a new principal type for applications. Application principals respect permissions in the same way as users and groups, so integrations can be given only the access they need.

## Improvements

* Added a New View button to the menu in Designer
* Added an Open in Adaptive Designer button to User Tasks in Workflow
* Creating a new table now lets you choose whether it's added to the sidebar menu
* The Get Rapid Item service task now shows a clear error when the target list or item can't be found
* Links in the External Page component that open a new tab or navigate the parent page now work

## Bug Fixes

* Fixed an issue where CSV exports could be missing rows
* Fixed an issue where copying an expression from a labelled Workflow element copied the label instead of the reference
* Fixed an issue where deleting a condition watcher in Adaptive Designer left its expression behind
* Fixed an issue where cascading lookups crashed the page when the linked list had no title field
* Fixed an issue where large uploads failed because of a field size limit
* Fixed an issue where document introspection in DocX templates stopped working
* Addressed styling issues with the public form URL in the state menu
