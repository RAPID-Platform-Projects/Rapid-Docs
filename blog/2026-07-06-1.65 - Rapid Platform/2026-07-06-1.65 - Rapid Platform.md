# v1.65 — Rapid Platform

We're excited to announce new improvements live on Rapid Platform **Monday, July 6th**

## Improvements

* The Activity Feed now supports emails saved in the modern Outlook .msg format
* Field description tooltips now stay on screen on mobile devices

## Bug Fixes

* Fixed an issue where only the last file was saved when uploading multiple files with the same name to an Embedded File component on a public form, such as when taking several photos on mobile
* Fixed an issue where Adaptive Documents set to fetch on load cleared their prefilled values when there was no item to fetch
* Fixed an issue where Adaptive Designer crashed when switching between large documents
