# v1.66 — Rapid Platform

We're excited to announce new improvements live on Rapid Platform **Friday, July 31st**

## Bug Fixes

* Fixed an issue where CSV exports could return rows in an inconsistent order across pages
* Fixed an issue where searching in a lookup didn't respect cascading lookup filters
* Fixed an issue where fetch connectors in Adaptive Documents could fail after saving progress and reloading the form
* Fixed an issue where edits to existing records weren't saved when syncing data from a workbook
* Fixed an issue where the Gantt component failed to load
