Intermediate Boundary Events

Element TypeSymbolFunction
Boundary EventThe default boundary event. This element cannot be configured, and should be changed to another element type.
Message Boundary EventAutomation of this event is not implemented at the time of writing.
Timer Boundary EventGenerates a new token from a task, once the specified Duration has elapsed. Discards all other active tokens.
Escalation Boundary EventAutomation of this event is not implemented at the time of writing.
Conditional Boundary EventAutomation of this event is not implemented at the time of writing.
Error Boundary EventWhen the associated element throws an error, the Error Boundary Event creates a token. The previous token that arrived on the element is discarded.
Cancel Boundary EventAutomation of this event is not implemented at the time of writing.
Signal Boundary EventAutomation of this event is not implemented at the time of writing.
Compensation Boundary EventAutomation of this event is not implemented at the time of writing.
Message Boundary Event (non-interrupting)Automation of this event is not implemented at the time of writing.
Timer Boundary Event (non-interrupting)This event generates a new token upon the configured Duration elapsing. However, it does not delete all other active tokens.
Escalation Boundary Event (non-interrupting)Automation of this event is not implemented at the time of writing.
Conditional Boundary Event (non-interrupting)Automation of this event is not implemented at the time of writing.
Signal Boundary Event (non-interrupting)Automation of this event is not implemented at the time of writing.
